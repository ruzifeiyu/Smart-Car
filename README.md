# Smart-Car

用于集中管理智能车竞赛相关代码，支持多人协作开发，并让每一次代码变更都可追踪、可解释。

## 项目目标

- 集中存放竞赛相关代码（感知、控制、调参、工具脚本等）
- 支持队友分工协作和持续完善
- 通过规范化提交与评审，让所有成员都清楚“改了什么、为什么改”

## 推荐协作流程（GitHub）

1. 从 `main` 拉分支开发（例如：`feat/motor-pid`、`fix/camera-calib`）
2. 每次改动使用清晰提交信息，建议格式：
   - `feat: 增加xxx能力`
   - `fix: 修复xxx问题`
   - `docs: 更新xxx说明`
3. 提交 Pull Request（PR）并至少由 1 名队友 Review 后合并
4. 合并后保留 PR 记录，作为变更历史和决策依据

## 变更可视化与“为什么改”

- 使用 GitHub 的 PR Diff 直接查看代码差异
- 在 PR 描述中强制填写：
  - 变更内容（What）
  - 变更原因（Why）
  - 验证方式（How to verify）
- 在关键 PR 中附上日志截图、测试结果或赛道表现对比，便于复盘

## 约定建议

- 小步提交：一次提交只做一件事，便于回溯
- 重要参数变更需写明依据（实验数据/现象）
- 任何人接手代码时，可优先阅读最近 PR，快速理解背景
